# 🕒 Relógio Digital

Um relógio digital moderno, minimalista e responsivo desenvolvido com HTML, CSS e JavaScript.

## 🚀 Demonstração

Projeto criado com foco em:
- Layout Flexbox
- Design minimalista
- Responsividade
- Organização de código

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox + Media Queries)
- JavaScript

## 📱 Responsividade

O projeto é totalmente responsivo, adaptando-se para:

- 💻 Desktop
- 📱 Dispositivos móveis

## 🎨 Estilo

Design minimalista com:
- Gradiente moderno
- Layout centralizado
- Tipografia clean
- Estrutura organizada


## 📚 Aprendizados

Neste projeto pratiquei:

- Estruturação semântica com HTML
- Flexbox para centralização
- Uso de `min-height`
- Responsividade com `@media`
- Organização de layout
